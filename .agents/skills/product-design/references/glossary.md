# Glossary

Product vocabulary used across Jùlaba. All terms in French.

## Actors & Roles

| Term | Definition | Context |
| ---- | ---------- | ------- |
| Marchand(e) | A market vendor selling goods | Primary user of the marchand surface |
| Identificateur | A field agent who enrolls and validates market actors | User of the identificateur surface |
| Producteur(rice) | An agricultural producer | Actor type for enrollment |
| Coopérative | A producer cooperative | Actor type for enrollment |
| Acteur | Generic term for any enrolled entity | Backoffice term |
| Administrateur | A backoffice user | Backoffice role |

## Geography

| Term | Definition |
| ---- | ---------- |
| Zone | A geographic sales territory (Adjamé, Cocody, Bouaké, etc.) |
| Région | A group of zones (Abidjan, Centre, Ouest, Nord) |
| Territoire | Synonym for zone in formal contexts |

## Enrollment & Validation

| Term | Definition |
| ---- | ---------- |
| Enrôlement | The process of registering a new market actor |
| Dossier | An enrollment case file |
| Brouillon | A saved but unsubmitted draft dossier |
| Validation | The act of approving a dossier |
| Rejet | The act of rejecting a dossier (requires reason) |
| Identifiant | A unique ID assigned to an enrolled actor (e.g., M-0845) |

## Commerce

| Term | Definition |
| ---- | ---------- |
| Caisse | Cash register / point of sale |
| Vente | A sale transaction |
| Dépense | A business expense |
| Stock | Product inventory |
| Panier | Shopping cart (caisse) |
| Fond de caisse | Starting cash amount for a session |
| Solde | Balance (income minus expenses) |
| Monnaie | Change given back to customer |

## Money

| Term | Definition |
| ---- | ---------- |
| FCFA | Franc CFA, the currency. No subunits. Stored as integer. |
| Billet | A banknote denomination (500, 1000, 2000, 5000, 10000 FCFA) |

## Backoffice

| Term | Definition |
| ---- | ---------- |
| Tableau de bord | Dashboard |
| Journal d'audit | Audit log |
| Permission | Access right tied to a role |
| Mission | An enrollment target assigned to a zone/agent |
| Supérvision | Real-time monitoring of field operations |
| Modération | Content and behavior review |

## Voice

| Term | Definition |
| ---- | ---------- |
| Tata Nanti Lou | The voice assistant's name |
| Réveil (wake word) | "Jùlaba" — activates the voice system |
| Intent | A parsed voice command (vente, dépense, navigation, etc.) |
| PTT | Push-to-talk — hold mic to record |

## Technical

| Term | Definition |
| ---- | ---------- |
| Soleil mode | High-contrast mode for outdoor sunlight |
| Nouchi | Ivorian street slang (used in voice parsing, never in UI text) |
| RBAC | Role-Based Access Control |
